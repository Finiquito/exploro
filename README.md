# Exploro

Nombre interno de **Rutas de Chile by WOM**: rutas naturales, históricas y urbanas de 45 minutos a 3 horas, con juego, aprendizaje y premio.

- Plugin de TypeDock (PHP + Latte): admin, panel de tiendas y API.
- App web móvil (PWA con Vite y MapLibre) que funciona sin señal.

La estructura del proyecto, el modelo de datos, los desafíos y los auspicios están en [`docs/ESTRUCTURA.md`](docs/ESTRUCTURA.md).
